# 🎬 Netflix GPT – AI Movie Recommendation System

## 🚀 Overview

Netflix GPT is an AI-powered movie recommendation web application that helps users discover movies and TV shows based on their preferences.
It uses intelligent search and recommendation logic to suggest personalized content, similar to Netflix.

---

## ✨ Features

* 🔍 Search movies using AI (GPT-based recommendations)
* 🎯 Personalized suggestions based on user input
* 📊 Dynamic movie listing with posters and details
* 🔐 Authentication (Login / Signup)
* 🌐 Responsive UI for all devices
* ⚡ Fast and smooth user experience

---

## 🛠️ Tech Stack

**Frontend:**

* HTML5

* JavaScript
* React.js

**Backend:**

* Node.js

**API & Tools:**

* OpenAI API (for AI recommendations)

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/netflix-gpt.git
```

2. Navigate to project folder:

```bash
cd netflix-gpt
```

3. Install dependencies:

```bash
npm install
```

4. Add environment variables:
   Create a `.env` file and add:

```
REACT_APP_OPENAI_API_KEY=your_openai_key
REACT_APP_TMDB_API_KEY=your_tmdb_key
```

5. Start the application:

```bash
npm start
```
